> 对应《机器学习》期末项目“可运行端到端原型”的六项硬性要求。  
> 验证环境：Windows 11 + Python 3.12.6，网页版运行于 `http://127.0.0.1:8000`。

## 1. 任务入口

- **用户输入**：一条课程群里的自然语言消息（最多 500 字），支持口语、错别字、无标点，例如“学习通打不开，一直显示 502”。
- **Agent 输出**：`label / label_cn / confidence / route_to / priority / needs_review / review_reason / reply / sources / ticket_id / steps / resolution`。
- **成功判定**：
  - 分类：测试集 Macro-F1 ≥ 0.85（实测 0.9275）；
  - 自动答复：错误率 ≤ 5%（实测 0/130）；
  - 复核率 ≤ 30%（实测 22.1%）；
  - 单条延迟 < 50 ms（实测均值 5.5 ms）；
  - 所有自动答复必须带知识库出处，否则转人工。

## 2. 任务流程与状态

| 步骤 | 作用 | 失败/分支 |
|---|---|---|
| ① 输入校验 | 拒绝空、单字符、重复噪声；超长截断 | 返回 `rejected` 与提示 |
| ② 文本清洗 | 全角转半角、压缩空白、保留数字/英文 | — |
| ③ ML 分类 | 输出五类概率，取最大类与置信度、类别间距 | 模型异常→降级转人工 |
| ④ 决策 | 低置信度/歧义/短文本/高影响意图→复核 | `pending_review` |
| ⑤ 知识库检索 | 类别过滤 + 关键词 + TF-IDF 余弦，低于阈值视为无答案 | KB 异常→转人工 |
| ⑥ 路由与落库 | 映射责任方、优先级，写 SQLite | DB 异常→标记 degraded |
| ⑦ 生成答复 | 只用 FAQ 原文与固定模板，附条目号/来源/相似度 | 无答案→转人工 |
| ⑧ 结论 | `auto_answered / auto_closed / routed / pending_review / rejected` | 写入 trace |

网页右侧的“Agent 处理轨迹”逐条展示上述 8 步，结构化 JSON 可在“结构化输出”中复制。

## 3. 机器学习组件

- **输入**：清洗后的中文短文本。
- **特征**：`TfidfVectorizer(char_wb, 2–4)` + `TfidfVectorizer(jieba, 1–2)`，`sublinear_tf=True`。
- **模型**：`ComplementNB(alpha=0.4)`，在 900 条训练集上拟合，在 228 条开发集上与其他模型比较并按 Macro-F1 选中。
- **训练/推理**：`python -m src.train` 训练并 `joblib.dump`；Agent 启动时加载，`predict_proba` 输出五类概率。
- **对任务的贡献**：把“读消息判断类型”变成可量化的五分类，测试集 Macro-F1 0.9275，较关键词规则 0.8174 提升约 11 个百分点。
- **基线/对照**：规则基线、ComplementNB、校准 LinearSVC、LogisticRegression、单通道特征消融，结果在 `outputs/model_comparison.csv`、`outputs/feature_ablation.csv`。

## 4. 工具与数据连接

- **FAQ 知识库**：`data/kb_faq.csv`，28 条课程/教务通用说明，字段含 `faq_id, question, answer, category, owner, source`。
  - 检索方式：先按预测类别过滤，再用意图关键词与字符 TF-IDF 余弦相似度混合排序；低于 0.32 视为无可靠答案。
  - 输出：最多 3 条，附来源、责任方、相似度；Agent 只引用第 1 条。
- **SQLite 工单库**：`data/agent_tickets.db`，表 `tickets` 记录原文、类别、置信度、责任方、状态、复核原因、答复与完整 trace；复核队列可标记 `resolved/closed`。
- **数据来源与许可**：1395 条工单由 `src/data_gen.py` 模板合成，不含真实学生信息；FAQ 为通用说明模板；依赖许可证见 `docs/复用组件清单.md`。
- **使用边界**：知识库只覆盖标准化问题（命中率 47.2%），具体课程政策以任课教师/教务正式通知为准；系统不自动执行任何学籍或成绩操作。

## 5. 失败与安全处理

| 情形 | 处置 |
|---|---|
| 空输入 / 单字符 | 拒绝，提示补充课程、平台或题号 |
| 重复噪声（“啊啊啊啊”） | 拒绝，提示用一句话描述问题 |
| 超长输入（>500 字） | 截断后处理，trace 记录“已截断” |
| 低置信度（<0.84） | 转人工复核，不自动给结论 |
| 类别歧义（前两类差距 <0.06） | 转人工复核 |
| 高影响申请（调课/延期/复核/免修等） | 即使置信度高也强制人工确认 |
| 知识库无答案 | 不编造，转责任方人工答复 |
| 知识库/数据库故障 | 结果标记 `degraded`，提示人工处理，不假装成功 |
| 模型文件缺失 | 启动即报错并提示先运行 `python -m src.train` |

自动验证：`outputs/failure_handling.csv` 记录 5 类异常输入的处置；`tests/test_smoke.py` 覆盖空输入、噪声、高影响复核、知识库命中与 Web 接口。

## 6. 可复现交付

```bash
pip install -r requirements.txt
python -m src.data_gen --seed 42      # 生成 1395 条数据与 FAQ
python -m src.train                   # 训练 + 阈值 + 测试指标
python -m src.evaluate                # 端到端评估 + 消融 + 异常输入
python -m src.make_figures            # 生成报告图表
python -m src.webapp --open           # 启动网页
python -m unittest discover -s tests -v   # 8 个冒烟测试
```

- 随机种子固定为 42，数据、划分、阈值与测试指标可复现；
- 模型文件与全部指标已随包提供，无密钥、无账号、无真实个人信息；
- 测试样例见 `data/test_samples.csv`（12 条，覆盖正常、边界、拒绝、复核四类）；
- 本次冒烟测试结果：**8 个测试全部通过（0.568 s）**。
